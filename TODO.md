### Features that are not built
- [ ] **Model container, what is still open**: `forge encrypt`, `forge adapter` and `forge sign` hold the whole file in memory; decrypted weights of a sealed model stay resident while it is open; no importer option writes the binary blueprint (convert with `forge blueprint`); encrypted files cannot be sharded; the blob store has no garbage collection and no remote fetch; the calibration rule is an untuned heuristic and there is no activation calibration; no PEFT LoRA importer. ([format.md](docs/format.md), [modelfile.md](docs/modelfile.md))
- [ ] **ONNX importer**: convolution, pooling, instance / group norm and resize only at batch 1; no 3-d convolution, non-integer Resize, strided Slice, Tile, Einsum, TopK, control flow, RNN or quantised operators; no integer division or comparisons at run time. ([modelfile.md](docs/modelfile.md#onnx-graphs))
- [ ] **Diffusion and streaming sessions**: one latent at a time, scheduler arithmetic on the host; no VAE / text encoder / image or audio I/O; not in `forge-serve` or the C ABI; the streaming runner is single-threaded. **Self-speculation**: the draft recomputes the early layers (no KV sharing with the verify pass); never timed. ([inference.md](docs/inference.md))
- [ ] **Model families**: Phi-2, Mamba, UNet / DiT denoisers and the Whisper decoder have no template (a denoiser or a streaming encoder can be imported as a blueprint directory and run through `session diffusion_loop` / `session streaming`, tested on tiny models only); Phi-3 LongRoPE (128k variants) is refused. No image or audio front end (resize / normalise, log-mel): `forge embed --input` takes preprocessed f32. ([modelfile.md](docs/modelfile.md), [inference.md](docs/inference.md))
- [ ] **Embeddings**: no batch axis in the graph (`session::embed_batch` and `/v1/embeddings` take several inputs per call and run them as a loop with shared setup); neither the C ABI nor `/v1/embeddings` serves the vision and audio encoders. ([serve.md](docs/serve.md), [capi.md](docs/capi.md))
- [ ] **forge-serve**: one model per process; no HTTP/2, response compression or `HEAD`; rate limits and quotas are per process and in memory; no TLS certificate reload or OCSP stapling; tool calls: Mistral's `[TOOL_CALLS]name[ARGS]{...}` and Llama's `<function=name>` forms are not parsed, arguments are not validated against the schema in `auto` mode; no PEFT-directory converter for `--lora`, no loading or unloading of adapters while serving. ([serve.md](docs/serve.md))
- [ ] **GPU**: `transpose`, `l2_normalize`, `masked_mean`, the resize ops and `batch_norm` still run on the host on every device; the device kernels for `attention_bias`, `layer_norm`, `gelu`, convolution, pooling and `group_norm` are untuned direct kernels; no eviction while a CUDA/HIP stream capture is open, and a stale CUDA/HIP capture that holds an evicted encoded weight or a macro-stamped kernel cannot be re-recorded (it throws); `gpu::prims` has no device FFT and no fused-epilogue matmul kernel; `pipe:auto` hands activations between stages through host memory (no peer copies, no per-layer byte accounting); Metal has no kernel program cache and no graphs; stream-K prefill (`FORGE_MMA_STREAMK`) is off by default until a token divergence is explained. ([gpu.md](docs/gpu.md))
- [ ] **CPU int8 activations and accuracy**: the int8-activation quantised matmul (x86 default, CUDA / HIP) deviates from the exact quantised result by up to about 1.6 % of the largest output on wide-range inputs; there is no per-model switch other than `FORGE_CPU_INT8=0`. ([gpu.md](docs/gpu.md) "Quantised matmul: exact and int8-activation paths")
- [ ] **C ABI** (ABI 4): no log-probabilities, tool-call helpers, lookup decoding, diffusion / streaming sessions, vision / audio embedding inputs, adapter unload or background batch worker; `forge_aot_precompile` writes plan sidecars only. ([capi.md](docs/capi.md))
- [ ] **AOT**: device plans are not serialised (CPU only); LoRA adapters are not baked in; plans for entry points, early-exit sessions and graphs with symbolic dimensions other than `seq` are compiled at run time; `--embed-weights` refuses sharded models; sequence lengths are exact (no bucketing); the pass-pipeline version is bumped by hand. ([aot-models.md](docs/aot-models.md))
- [ ] **Script AOT**: no automated test for a baked `--mem-limit`, a baked FSS policy or `integrity.scripts` on the executable. Model AOT does not drive MSVC's `cl.exe`. ([aot.md](docs/aot.md), [aot-models.md](docs/aot-models.md))
- [ ] **OS layer**: native Wayland clipboard, portal `OpenFile`, Secret Service; `SO_REUSEPORT` and client TCP fast open on Windows; the per-OS "unsupported" entries of [os-parity.md](docs/os-parity.md). ([os-audit.md](docs/os-audit.md) S11)
- [ ] **RPC**: no OCSP or CRL fetching; device ops have no per-model scope; uploaded weights have no per-rule storage cap, encoded weights are not sent by handle, and activations still travel with every op. **Security**: the known gaps listed in [security.md](docs/security.md#known-gaps).
- [ ] **Scheduler**: the engine runs on `task::sched` with `FORGE_TASK_SCHEDULER=sched` (same bits), but `pool` stays the default: on the one machine measured (4 cores, loaded) `sched` is 1.6 to 2.6 times slower on short loops (decode). Its per-loop start-up cost has not been profiled or reduced. ([support.md](docs/support.md#engine-executor-taskenginehpp))
- [ ] **simd follow-ups**: Tier A's hand-written byte search, i32 prefix sum and sort partition exist for AVX2 / AVX-512 only (other tables use the 8-byte integer path or compiler-vectorised loops; `vec_types.hpp` now has the byte vectors to write them with); the SSE and WebAssembly `seq` tables compute `fma` per lane; no conversions to C++26 `std::simd`; `std::mdspan` overloads untested against libstdc++. ([simd.md](docs/simd.md))
- [ ] **Fusion**: the matmul epilogue (bias + activation) is a separate block-wise pass, not inside the GEMM loop; `rope` + `attention` are not fused on the CPU; row chains are host-plan only and unmeasured on a real model; natively compiled plans run their steps unfused. ([graph.md](docs/graph.md#fusion))
- [ ] **CPU kernels**: interleaved prefill tiles, multi-product dispatch and per-token serial work on the pool for the quantised matmul; a head-major int8 KV layout; the chunked attention kernel as the default with f32 KV (not shown faster yet). ([STATUS.md](docs/STATUS.md), [inference.md](docs/inference.md#notes-and-limits))
- [ ] **Load balancer proxy**: HTTP/1.1 only, no TLS, upstream responses are buffered whole (no SSE pass-through). ([loadbalancer.md](docs/loadbalancer.md))
- [ ] **Memory**: the "Not built yet" list of [memory.md](docs/memory.md#not-built-yet).

They need codebook grids that FORGE does not carry; FORGE is a clean-room design and the codebooks will not be copied. The importer refuses a file that uses one with an error that names the type. (Owner decision 2026-11-13; [modelfile.md](docs/modelfile.md#gguf-tensor-types))
